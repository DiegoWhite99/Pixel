Mis dispositivos

Conectar un ESP32 por WiFi

  1. Enciende el ESP32. Si no encuentra su red, abre la red Pixel-Config y el LED se pone morado. También puedes abrirla manteniendo pulsado el botón BOOT 3 segundos.
  2. Desde el móvil, conéctate a Pixel-Config (clave pixel2026).
  3. Se abre la página de configuración. Si no se abre, entra a http://192.168.4.1.
  4. Elige la red WiFi y pon como IP del servidor …. Al guardar, el ESP32 se reinicia y aparece en esta lista.

Requiere el firmware nuevo con portal (Pixel_portal.ino).

Bluetooth

Sin datos

Con el firmware nuevo, el ESP32 se anuncia por Bluetooth y cada 30 segundos busca los dispositivos que tiene cerca. La lista aparece en su tarjeta.

Es Bluetooth de bajo consumo (BLE): sirve para ver dispositivos y, más adelante, para configurarlo desde el móvil. No sirve para audio: no puede hacer de altavoz ni conectarse a auriculares.
